## ✨ 功能

- 指定要派的果實：水果＋花（例如「柳橙＋鼠尾草」），也可以選「任何水果」「任何花」「普花」
- 派遣顏色依序嘗試（最多 3 個），第一個顏色不夠 6 隻就換下一個
- 距離上限、探險時間上限：太遠或太久的探險不派
- 懸浮面板 ▶ 開始、■ 停止；執行中按**音量下鍵**也能立即停止
- 問題回報：一鍵匯出紀錄，傳給作者查問題

## 安裝

1. 點開下載的 APK 安裝。手機問「是否允許安裝未知的應用程式」時，允許你用來開檔案的 App（例如瀏覽器、LINE 或「我的檔案」）。
2. 如果 Google Play 安全防護跳出警告，選「更多詳細資料」→「仍要安裝」。

更新時直接安裝新版覆蓋，設定都會留著。

## 開啟無障礙服務（只要一次）

1. 打開 Pikpik，按上方紅色卡片的「前往無障礙設定」。
2. 找到 Pikpik（可能在「已下載的應用程式」或「已安裝的服務」裡）→ 開啟。
3. **開關按不下去，或顯示「受限制的設定」**（Android 13 以上常見）：
   設定 → 應用程式 → Pikpik → 右上角「⋮」→「允許受限制的設定」，再回到第 1 步。
4. 回到 Pikpik，右上角顯示綠色「無障礙已開啟」就完成了。

## 使用

1. 在 Pikpik 設定目標果實、派遣顏色、派遣限制。
2. 按下方「開啟懸浮面板」。
3. 打開遊戲 → 探險列表，等畫面停穩，按懸浮面板的 ▶。Pikpik 會先回到列表頂端，再一路往下找。
4. 想停止：按面板的 ■，或按手機的**音量下鍵**。

執行時請不要碰螢幕，手指會干擾自動操作。

## 回報問題

遇到點錯、卡住、該派的沒派：

1. 打開 Pikpik，捲到最下面「問題回報」→「匯出紀錄」，把 zip 傳給作者。
2. 附上一句話說明發生什麼事。

zip 裡有：手機型號與螢幕大小、你的 Pikpik 設定、執行紀錄、最近幾張判斷失敗時的截圖。截圖是遊戲畫面，可能拍到地點名稱或遊戲地圖（會顯示你附近的位置）；介意的話，傳送前可以刪掉 zip 裡 debug 資料夾的截圖。

目前實測過的手機：Samsung A55、Pixel 7a。
