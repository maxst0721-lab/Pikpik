## ✨ 功能

四個分頁，各自設定、各自啟動：

- **收果**：指定要派的果實（顏色＋花，例如「紅＋鼠尾草」），也可以選「任何花」「普花」；每條可以設定收幾顆
- **派盆**：指定要拿的花苗顏色（8 色）和分類（例如「餐廳」「森林/鍬形蟲」），每條可以設定拿幾盆
- **餵花**：依序餵指定的花蜜，每種用設定的個數（或用完），花瓣到容量上限就換下一種
  - 用遊戲內的搜尋找花蜜；也可以選「所有花」：庫存超過 N 的花蜜每種餵 M 個（不含普花的精華）
  - 長按看隊伍的吃飽程度，餵到設定的輪數（預設 5/6，不會餵到禿頭）就換隊
  - 先催花苞（選用）：全新的隊伍先餵白色精華，那一輪花瓣雙倍
- **蘑菇**：蘑菇戰鬥時間計算器（不自動操作）
  - 懸浮面板按「戰鬥」截圖辨識剩餘生命值和工作力，存成資料卡：算出幾點打完、要在目標時間打完該幾點邀請隊友、需要多少工作力；可以設邀請鬧鐘和打完鬧鐘
  - 按「查詢」馬上看目前這場幾月幾日（星期）幾點打完、能拿幾星，不存資料卡
  - 列表按相機再點進去截圖，資料卡會帶上地名和封面；可以記錄是哪個帳號打的
  - 同一場截了兩次會標「重複」，可以一次選取刪除
  - 按「圖鑑」截獎勵或參加前的畫面，自動更新蘑菇圖鑑的星等門檻和生命值
- 收果、派盆：派遣顏色依序嘗試（最多 3 個）；距離上限、探險時間上限、最多派遣次數
- 花朵圖鑑、派盆分類、蘑菇圖鑑：遊戲出新花、新分類或新蘑菇時可以自己加
- 外觀：跟隨系統／淺色／深色；選單「檢查更新」顯示目前版本、打開下載頁
- 懸浮面板 ▶ 開始、■ 停止；執行中按**音量下鍵**也能立即停止。面板可以縮成小圖示：短按切換模式、長按展開，拖到下方垃圾桶關閉
- 問題回報：一鍵匯出紀錄，傳給作者查問題

### 1.6 更新內容

- 收果：每次從目前畫面開始找，到底後回頂端從頭再檢查一輪
- 收果、派盆：中斷後 30 分鐘內按 ▶，可以選「延續上一輪」或「重新開始」
- 收果：等待模式，每隔幾分鐘自動再跑一次
- 收果：某個顏色不夠時，這次之後先跳過；所有顏色都不夠就停止
- 收果：超過 50 公里的地點，同地名的其他果實直接跳過
- 目標花名結尾的「花」可寫可不寫
- 蘑菇：在列表按相機、點進去再按一次，資料卡會帶上地名和封面
- 蘑菇：名稱和生命值、工作力辨識更準；還沒開打的蘑菇會顯示「還沒開打」
- 蘑菇：資料卡可以記錄帳號（目前帳號自動填、懸浮面板可切換、依帳號篩選、鬧鐘通知寫帳號）
- 蘑菇分頁改版：每筆資料一張卡片、長按多選刪除、拖曳排序、左下「＋」新增；詳細頁的截圖固定不動、可以收合
- 蘑菇：鬧鐘響了之後那張卡會發亮（邀請＝橘紅、打完＝綠），點通知直接捲到那張卡；邀請鬧鐘響過的卡可以設定隊友人數，馬上算出每人平均要多少工作力
- 蘑菇：邀請時間不是今天時會寫「明天」或日期；更新圖鑑時的蘑菇名稱辨識更準

### 1.5 更新內容

- 蘑菇資料卡檢查重複：同一隻蘑菇、同尺寸、打完時間相差 1 分鐘內，較新的那張標「重複」；選取模式可以「選取重複」一次刪除

- **你的設定只存在手機裡**，不會傳給作者或任何伺服器。沒有廣告，也不追蹤你的使用情形。
- **無障礙服務的用途**：截取畫面辨識遊戲內容、模擬點擊和滑動、顯示懸浮面板、偵測音量下鍵來停止，以及餵花時把花名填進遊戲的搜尋框。Pikpik 只在你按 ▶（蘑菇面板是「戰鬥」「圖鑑」）之後才操作，截圖只在手機上辨識。以下兩種會存在手機裡：判斷失敗時的除錯截圖（只保留 2 天，可在 App 裡一鍵清除）、蘑菇資料卡的戰鬥截圖（資料卡過期會自動刪除）。
- **通知、鬧鐘與提醒權限**只用在蘑菇的邀請鬧鐘和打完鬧鐘；「鬧鐘與提醒」不允許也能用，只是省電時鬧鐘可能晚幾分鐘。

## 安裝

1. 點開下載的 APK 安裝。手機問「是否允許安裝未知的應用程式」時，允許你用來開檔案的 App（例如瀏覽器、LINE 或「我的檔案」）。
2. 如果 Google Play 安全防護跳出警告（例如「有害應用程式」），選「更多詳細資料」→「仍要安裝」。

更新時直接安裝新版覆蓋，設定都會留著；安裝後請重新開啟無障礙服務。

## 開啟無障礙服務（只要一次）

1. 打開 Pikpik，按上方紅色卡片的「前往無障礙設定」。
2. 找到 Pikpik（可能在「已下載的應用程式」或「已安裝的服務」裡）→ 開啟。
3. **開關按不下去，或顯示「受限制的設定」**（Android 13 以上常見）：
   設定 → 應用程式 → Pikpik → 右上角「⋮」→「允許受限制的設定」，再回到第 1 步。
4. 回到 Pikpik，紅色卡片消失就完成了（右上角選單 ☰ 的「無障礙設定」會顯示「已開啟」）。

## 使用

1. 在 Pikpik 選分頁（收果／派盆／餵花／蘑菇），設定目標和限制。
2. 按下方「開啟懸浮面板」，會用目前分頁的模式。
3. 收果、派盆：打開遊戲 → 探險列表，等畫面停穩，按懸浮面板的 ▶。Pikpik 會先回到列表頂端，再一路往下找。
   餵花：停在隊伍畫面（下方有花蜜球和哨子），按 ▶。
4. 想停止：按面板的 ■，或按手機的**音量下鍵**。
5. 蘑菇：在蘑菇分頁開啟懸浮面板，在戰鬥畫面按「戰鬥」、在獎勵或參加前的畫面按「圖鑑」。

執行時請不要碰螢幕，手指會干擾自動操作。

## 回報問題

遇到點錯、卡住、該派的沒派：

1. 打開 Pikpik，右上角選單 ☰ →「問題回報」→「匯出紀錄」，把 zip 傳給作者。
2. 附上一句話說明發生什麼事。

zip 裡有：手機型號與螢幕大小、你的 Pikpik 設定、執行紀錄、最近幾張判斷失敗時的截圖。截圖是遊戲畫面，可能拍到地點名稱或遊戲地圖（會顯示你附近的位置）；介意的話，傳送前可以刪掉 zip 裡 debug 資料夾的截圖。

目前實測過的手機：Samsung A55、Pixel 7a。
